Matchable Products + Alternatives

Wireframes only — no implementation yet. Goal: split AI search results into Matchable products (best intent fit) and Alternative recommendations (compatible / broader options).

Feasibility: Yes. The AI service already knows matchType: exact | recommended | none, but today it returns either exact matches or a recommended fallback — never both in one response. To show two sections at once, we need a small API change to return products + alternatives together. Magento UI then renders two blocks.

Data split (backend)

Bucket Meaning Source today
Matchable products Precise catalog hits for the detected goal / filters matchType: "exact" → products[]
Alternatives Broader / compatible options when exact is thin, OOS, or user asked for alternatives matchType: "recommended" path (broad search) — currently replaces exact list

Proposed API shape (after approval):

{
{
  "matchType": "exact" | "recommended" | "mixed" | "none",
  "products": [ /* matchable */ ],
  "alternatives": [ /* compatible / broader */ ],
  "summary": "…"
}
