2. Shopper journey (step by step)

  1. Search Shopper enters a natural-language query in the Magento header search and submits.
  2. Land on AI page Instead of classic keyword PLP, they see “AI Commerce Assistant” with “Your search” echoed. Page auto-calls start with that query.
  3. Goal Detected Goal title echoes the shopper query (“blue yoga pants for women under $50”). Filter tags update as the shopper answers follow-ups.
  4. AI suggestions (clarify) If intent is unclear, AI asks one focused question with clickable chips (and optional free text). Each answer continues the same session.
  5. Results When ready, AI returns ranked products. UI shows Best Match / Best Value, budget slider, sort, grid/list — still on the same page (no reload).

4. How AI suggestions should show

“Suggestions” = clarifying chips + optional free text while refining intent — not a separate chat bubble UI. Keep it PLP-like and scannable.

Element Rule Example
Question copy One question at a time. Short, shopper language. “What length are you looking for?”
Chips 3–5 options. Mutually clear. Last option can be soft (“No preference”). Full length · Capri · Shorts · No preference
Free text Always available under chips for nuance. “High-waisted, size M”
Goal tags Update after every answer so shopper sees “AI understood me”. ✓ Blue · ✓ Yoga pants · ✓ Under $50
Product badges Only on AI relevance order (page 1). Best Match, Best Value
Why line (optional) Short reason from AI (reasons[]) — builds trust. “blue · full length · in budget”
Do · suggestion UI

What length are you looking for?

Full length Capri Shorts No preference
Good: Fast tap, clear choices, one intent.
Don’t · suggestion UI

Please describe in detail your complete requirements including brand, color, size, material, occasion, and shipping constraints…

Option A with a very long label that wraps awkwardly Option B Option C Option D Option E Option F Option G
Avoid: Essay questions, 7+ chips, jargon.

Talking points for manager

  1. Entry: Same Magento search — no new URL for shoppers to learn.
  2. Conversation: AI asks only what’s missing; chips make it feel like guided search, not a chatbot.
  3. Trust: Goal Detected + tags show understanding; Best Match / Best Value explain ranking.
  4. Catalog: Final products always come from Magento catalog (via AI search), not invented items.
  5. Results: Matchable grid + Alternatives carousel (Option A approved).
