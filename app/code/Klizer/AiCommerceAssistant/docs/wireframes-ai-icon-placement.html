AI icon placement — recommendations + wireframes

Today the assistant only appears after Magento catalog search submit. Adding a persistent entry icon makes the experience discoverable without forcing every shopper through keyword search first.

Recommendation: Ship Option A (header search AI control) as primary, plus Option B (floating assistant button) for always-on access. Skip homepage hero and mini-cart icons in v1 — they add clutter without improving the core path.

1. Placement ranking

Priority Placement Why Looks good?
1 · Best Inside / beside Magento header search Matches mental model (“smarter search”). Lowest surprise. Reuses existing AI page flow. Yes — feels native, not a third-party chatbot
2 · Strong Bottom-right floating AI button Always available on PDP/PLP/CMS. Good for “help me find…” without leaving the page. Yes if compact + theme-colored; ugly if oversized or chatty
3 · Optional Category / classic PLP toolbar chip Helpful when browsing a category: “Ask AI to refine.” Good as text chip, not a second FAB
Defer Homepage hero CTA Marketing value only; competes with merchandising. Can look promotional, not product UI
Avoid Mini-cart / account menu / every product card Wrong context; icon spam. No

Mobile rules

  • Keep one FAB max; don’t stack chat + AI + back-to-top.
  • Header icon stays 28px so search field remains usable.
  • Panel should be full-width bottom sheet on mobile, not a 280px card.
  • Hide FAB when keyboard is open / on checkout.

7. How to wire in Magento (fit this module)

Layout: default.xml (or theme header)
  └─ block: klizer.aicommerceassistant.launcher
       template: launcher.phtml  → icon + optional FAB
       JS: launcher.js
            ├─ click header AI  → redirect to AI entry URL (empty q or landing)
            └─ click FAB        → open panel → submit → catalogsearch/result/?q=…

Reuse existing:
  • Module enable flag (aicommerceassistant/general/enabled)
  • AI results page (already replaces catalog search)
  • assistant.js start/message/context flow

Do not rebuild chat inside the FAB for v1 — use it as a doorway into the AI page.
Icon design Solid brand circle + “AI” or simple sparkle SVG. One accent color matching theme (teal/navy). No purple glow, no bounce loop.
Copy “Ask AI to shop” / “Find with AI” — shopping language, not “Chatbot” or “Support”.

8. What to avoid

PatternWhy it hurts
Intercom-style chat bubble everywhere Shoppers think it’s customer support, not product discovery
Icon on every product card Visual noise; kills merchandising
Auto-open panel on page load Aggressive; hurts conversion and trust
Different AI UIs (header + FAB + hero + PLP) Looks unfinished; pick 1–2 surfaces max
Ship order: (1) Header search AI icon → empty-query AI page, (2) FAB on non-AI pages, (3) Category “Ask AI to refine” only if classic PLP still exists alongside AI search.
